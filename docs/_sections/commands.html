Commands

CommandWhat it does
rmc install [--scope user] [--no-link]Wire the hooks; also puts rmc on PATH
rmc uninstallRemove only what RMC added
rmc doctorBackends, store, hook wiring, PATH
rmc statusFamilies, levels, precision, capture miss rate
rmc tree [--recent] [--family F] [-v]The graph; --recent is newest-first across families
rmc recall --prompt "…"What would be injected, and why
rmc trace --prompt "…"Every stage, ending in the verbatim block
rmc add "…" [--family F]Teach it now, reconciled against what is known
rmc conflicts / rmc resolve <id> [--drop]List and settle contradictions
rmc compactAttempt compressions that are due
rmc dream [--list] [--due] [--log] [--gists]Whole-store consolidation; --gists fills missing routing views
rmc evalReplay held-out work against every level of a lesson
rmc eval-recall [--save N] [--against N]Score retrieval against what was actually used; A/B two configurations
rmc tune [--rounds N] [--history]Let RMC propose and measure its own retrieval improvements
rmc migrate [--path D] [--apply]Convert an existing Claude skills library into lessons
rmc report --about "…"A redacted defect report. Sends nothing.
rmc events --kind KRaw telemetry
rmc config [key] [value]Read or set any setting

Any config key can be overridden per-run by an environment variable: recall.max_pack_tokens → RMC_RECALL_MAX_PACK_TOKENS. Full reference: docs/cli.md.
