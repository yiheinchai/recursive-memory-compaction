Agent memory that
shrinks as you use it.

Most memory systems get more expensive the longer you use them. RMC gets cheaper. Every time a lesson proves useful, it earns a shorter form — and the short form is what you pay for next time.

Step 01 / 07

Recall

You type a prompt. Before the agent sees it, RMC walks its lesson graph from the most abstract node down, asking the model which branches could possibly matter — never keyword matching — and injects the handful that survive. Usually zero extra model calls, because the answer is cached.

The problem

Memory normally rots in one of two ways.

Append-only stores grow until retrieval is guesswork and the context bill dwarfs the task. Aggressive summarisers throw away the exact port number, the one flag that mattered — and you find out when something breaks, not when it was dropped.

RMC's answer is that use is the only evidence worth compressing on. A lesson that was served but ignored earns nothing. A lesson that was actually used, on work that actually succeeded, has demonstrated slack — so it earns one attempt at a shorter form, and the shorter form has to pass a replay of the real work before it replaces anything.

01

Nothing is deleted

Compression adds a level above; the detailed original stays reachable underneath it.

02

Every drop is recorded

A shorter lesson carries a manifest of what it left out, so descent is a ranking problem, not a search.

03

Compression must be earned

The short form replays past successful work. If it can't reproduce the outcome, it's rejected.

The governing rule

The harness owns structure.
The model owns meaning.

There is no cosine similarity in RMC, no Jaccard index, no keyword bank. Code decides whether to ask — budgets, traversal order, caching, schemas. The model decides every question whose answer is a judgement: is this relevant, does this contradict that, did this survive compression, is this worth keeping.

Install

You don't drive it.

Install once, then work normally. RMC runs in hooks: it injects on prompt submit, reflects off-thread when a turn ends, mints and compresses when a session ends, and consolidates once a day. Every expensive step is detached, so nothing blocks your turn.

Python 3.10+, at least one of claude or codex, and zero third-party Python dependencies.

git clone https://github.com/yiheinchai/rmc
cd rmc && ./bin/rmc install \
  --target claude --target codex
Then, whenever you're curious
rmc status     # what it knows, what it cost
rmc tree       # the graph, by level
rmc recall --prompt "..."  # what it would inject
